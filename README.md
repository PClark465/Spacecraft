# Asteroid Belt — Unity Final Project

A 2D space shooter developed in Unity using C#.

## Download and Play

1. Open the **Releases** section of this GitHub repository.
2. Download the latest `Asteroid Belt.zip`.
3. Extract the ZIP file into a folder.
4. Run `Spacecraft.exe` to launch the game.

**Platform:** Windows 64-bit

## Features

- Player-controlled spacecraft
- Randomly spawning enemies
- UFO tracking behavior
- Asteroid movement and screen wrapping
- Enemy scoring system
- Sound effects and adjustable audio settings
- Main Menu, gameplay, and victory screen

## Source Code

The Unity project source is included in the `Assets`, `Packages`, and `ProjectSettings` folders.
